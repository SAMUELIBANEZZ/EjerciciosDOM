
# Práctica de Manipulación del DOM y Eventos en JavaScript 🚀

Este repositorio contiene un proyecto práctico enfocado en el aprendizaje y la implementación de la manipulación del Document Object Model (DOM) y la gestión de eventos utilizando JavaScript Vanilla (puro), integrado en una única página web junto con HTML5 y CSS3.

## 📋 Descripción del Proyecto

El proyecto se divide en tres ejercicios interactivos diseñados para afianzar conceptos clave del desarrollo frontend:

1. **Contador Interactivo:** Un módulo numérico que responde a eventos de clic (`click`) para incrementar, decrementar y reiniciar su valor, actualizando el DOM en tiempo real.
2. **Formulario sin Recarga (AJAX Simulation):** Un formulario de captura de datos (Nombre y Email) que intercepta el evento de envío (`submit`) mediante `event.preventDefault()`, procesando y mostrando la información sin necesidad de recargar la página.
3. **Generador de Color de Fondo Aleatorio:** Un botón que ejecuta un algoritmo matemático en JavaScript para generar códigos hexadecimales aleatorios y aplicarlos dinámicamente al estilo CSS del documento.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de la página.
* **CSS3:** Diseño responsivo, estilizado de contenedores usando Flexbox y transiciones suaves para mejorar la experiencia de usuario (UX).
* **JavaScript (ES6+):** Lógica funcional, manejo de variables (`let`, `const`), funciones flecha y *Event Listeners*.
